# User Management System

A simple CLI-based user management system built using Python. This project allows users to register and log in, with data stored persistently using file handling.

## 🚀 Features
- User Registration  
- User Login Authentication  
- File-based data storage (users.txt)  
- Input validation for existing users  

## 🛠️ Technologies Used
- Python  
- File Handling  

## ▶️ How to Run
1. Make sure Python is installed  
2. Run the following command:
   python user_system.py

## 📂 Project Structure
user-management-system/
 ├── user_system.py
 └── users.txt

## 📌 Sample Workflow
1. Select Register and create a user  
2. User data is saved in users.txt  
3. Select Login to authenticate  
4. System validates credentials  

## 🎯 Purpose
This project demonstrates basic programming concepts such as control flow, file handling, and user authentication logic.
